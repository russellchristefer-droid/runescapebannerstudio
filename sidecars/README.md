# Sidecars

These files are **not** the website.

The live desk is Node 22 + Vite on grok.me. Download a sidecar only if you want a one-file script on a machine that already has Python.

```bash
python3 sidecars/still_desk.py --still public/Falador.png --name Christefer
python3 sidecars/clip_bench.py clip.mp4 --in 2 --out 8
python3 sidecars/banner_studio.py serve
```

Kali Linux uses the same files. Install with apt, not an exploit kit: [kali/README.md](kali/README.md)
