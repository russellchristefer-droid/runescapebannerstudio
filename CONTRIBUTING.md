# Contributing

This is a small fan desk. Read the [README](README.md), [NOTICE](NOTICE), and [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md) before you open a PR.

Use Node 22. Run `npm ci` and `npm run ci:gates`.

Please do not add official Jagex® logos, cache dumps, live Wayback links, cheat clients, or gold-selling copy. Keep Old School RuneScape® and RuneScape® stills, quotes, and skills in their own folders. There should stay one PlaceRail, one painter, and one store — not a second nav on the card.

Do not commit secrets. Live badges belong in env vars. When you drop a skill pack on the plate, icons and levels have to stay inside the export box.

A still you add should be identification, not a ripped cache dump you cannot source. If Jagex or a wiki project would have a clean argument against the file, do not ship it.

Write like someone who has died to the mechanic. The wiki wins on numbers.
