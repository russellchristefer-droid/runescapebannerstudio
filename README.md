# RuneScape Banner Studio

Independent fan desk. Not Jagex.

## Run on any computer

Needs Node 22+.

```
git clone https://github.com/russellchristefer-droid/runescapebannerstudio.git
cd runescapebannerstudio
npm install
npm run dev
```

Open the URL Vite prints (port **8080**).

Town stills live in `public/` (Falador and the rest). Plate type is a fan replica in `public/fonts/`. This is a Node app, not an App Store build.

Live site: https://runescapebannerstudio.grok.me/
